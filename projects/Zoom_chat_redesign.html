Research: people lose chats and files

I surveyed 25 Zoom users (students, educators and professionals) and ran a heuristic evaluation of the chat and file-sharing interface. Most people rated both features as merely average, and the pain points were consistent.

“Cannot save chat history easily, I have to manually do it.”Survey respondent 25
“I will lose them when the meeting ends.”Respondent 1, on why they avoid sharing files in Zoom
“I did not know we can share files on Zoom.”Respondent 20
“It can require a lot of scrolling back to see what has been said earlier.”Respondent 9

What the evidence said

  • 18 of 25 agreed a Save Chat/Files button matters (rated 4 or 5).
  • Heuristic review found 5 visibility-of-status issues, 4 user-control issues and 3 consistency issues.
  • Recurring requests: better notifications, easier chat navigation, drag-and-drop sharing, automatic saving.

Three directions, one favorite

Brainstorming alone and with ChatGPT produced ideas in five themes: notifications, streamlined file sharing, user control, interface consistency and cloud integration. I took three directions into low-fidelity React prototypes and had the same 25-person survey group rate each.

Ratings are means on a 1–5 scale. All three scored high on access; version 3 won the most votes, while version 1 was the pick for people who wanted simplicity. Comments asked for a chat input box, color-coded tabs, a collapsible sidebar and a Save label that changes with the tab.

The final prototype

It merges version 1’s clarity, version 2’s layout and version 3’s customization, and adds what testers asked for.

Added from feedback

  • Fully collapsible sidebar for screen space
  • Color-coded tabs: blue chat, green files, violet settings
  • Save button that renames and recolors per tab
  • Chat input box and thumbs-up reactions

Customization

  • Adjustable sidebar width
  • Context-aware search for messages and files
  • Settings tab for notifications and dark mode

Reflection and next steps

  • Add automatic saving and better drag-and-drop, the two requests that survived both rounds.
  • Simplify the settings menu, which some testers found slightly complex.
  • Balance simplicity against desktop power use: one tester found it too simple for desktop.
  • Test with a larger, more varied sample, and with real tasks in live meetings. Both rounds used 25 volunteers recruited through personal and course networks, so results are directional.
